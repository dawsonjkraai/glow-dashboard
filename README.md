# Glow Dashboard

A touch-first dashboard for Home Assistant, made for wall tablets: a short setup builds it from what
your home has, and every card can then be moved, resized and swapped by touch. It lives in Home
Assistant's sidebar as an add-on.

[![Add this repository to your Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fdawsonjkraai%2Fglow-dashboard)

## Install

1. In Home Assistant, go to **Settings › Add-ons › Add-on store**, open the **⋮** menu, choose
   **Repositories**, and add `https://github.com/dawsonjkraai/glow-dashboard` (or press the button above).
2. Find **Glow Dashboard** in the store, install it and press **Start**.
3. Turn on **Show in sidebar** and open **Glow**.

Add-ons need Home Assistant OS or a Supervised install. The add-on's **Documentation** tab covers wall
tablets, the optional no-sign-in port, and what the add-on does for every screen.
